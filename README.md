# Varun Kumar — Portfolio

Hey! This is the source code behind my personal portfolio website. It's a one-page site that shows who I am, what I do, and how you can reach me.

## What's on the site

- **Hero** — quick intro about me
- **About** — who I am and what drives me
- **Skills** — the technologies I work with
- **Projects** — some things I've built
- **Experience** — where I've worked and what I did
- **Achievements** — a few highlights I'm proud of
- **Contact** — a form to get in touch with me
- **A terminal** — a fun command-line that introduces me
- **Aumpious** — a small AI assistant built into the site that can tell you about me and help with tasks

## Built with

- **React** — the UI library
- **Vite** — the build tool that makes everything fast
- **EmailJS** — powers the contact form (no backend needed)

## Run it on your computer

You need [Node.js](https://nodejs.org/) installed first.

```bash
# 1. Install the dependencies
npm install

# 2. Start the dev server
npm run dev
```

Then open the link it prints (usually `http://localhost:5173`).

To make a production build:

```bash
npm run build
```

The ready-to-publish files will be in the `dist` folder.
